## 1. Import (do p2 first)

For each file, in order **p2 → p1 → pilot**:

1. Log in at `https://survey.alpine-institute.eu/admin` (Keycloak, then `aiar-admin`).
2. Top menu **Surveys** → **Create survey** → tab **Import**.
3. **Select survey structure file** → choose the `.lss`. Leave "Convert resource links and expression fields" ticked.
4. Click **Import survey**. The summary should show no errors. Note the survey ID it reports.

## 2. Set the p2 URL in p1 and the pilot

The shipped p1 and pilot files link to `https://survey.alpine-institute.eu/index.php/343102?lang=en`.
- If p2 was imported as **343102**, nothing needs doing. Check the link once in the preview (page "Part two" → answer "Yes").
- If it got a different ID: open p2 → **Overview** → copy the survey URL. Delete the imported p1 and pilot, then rebuild and re-import them:
  `python3 scripts/aiw343_build_survey.py --p2-url '<copied URL>'`
  The same command takes `--expires 'YYYY-MM-DD HH:MM:SS'`, `--p2-expires`, `--close-date`, `--support` and `--ethics` (see 4).

## 3. Activate

Survey → **Activate this survey**. In the dialog, confirm exactly these values:

| Setting | p1 / pilot | p2 |
|---|---|---|
| Anonymized responses | Yes | Yes |
| Save IP address | No | No |
| Save referrer URL | No | No |
| Save timings | **Yes** | No |
| Date stamp | No | No |

Then **Save & activate**. When asked about a participant list, choose **open-access mode**. There must be no participant table.

## 5. Settings the .lss cannot carry (check by hand)

- **Global HTML/XSS filter** (Global settings → Security). If the import is done by a non-superadmin while the filter is on, the inline SVG and the `target`/`rel` link attributes are stripped. Import as superadmin, or check the demo picture and the p2 link afterwards.
- **Incomplete responses are stored** page by page (LimeSurvey default). Consent text fixed S358 to say so: incomplete responses are never analysed and are deleted at close. **Export only completed responses** (Export → 'Completion state: Completed responses only'), and at close delete the incompletes (Responses → filter 'incomplete' → delete).
- **Export.** Use Responses → Export → CSV, headings **question code**, responses **answer codes**, and include the timing columns (`interviewtime`, per-page times). `duration_s` comes from `interviewtime`. Then run `to_analysis_columns()` from `scripts/aiw343_build_survey.py`. The RemoteControl export needs the field list from `export_fields()`, because the default list leaves out timings.
- **Pilot.** Kept apart (own ID and table). Delete or archive it before launch.
- **p2 deletion.** Delete the p2 response table when recruitment ends, or after 12 months at the latest. Set a calendar reminder at launch.
