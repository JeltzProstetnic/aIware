Changed since the poster Since the poster, the paper answers questions raised at MoC7, in particular Johannes Kleiner's challenge to the theory's definition of consciousness. — Consciousness is defined as the ongoing process of running a self-model; the capacity for it is named separately. — One gate: a system has phenomenology or has none. Above the gate, levels vary on two axes, richness of content and depth of recursion. A new lowest level, minimal consciousness, sits below what report can detect. — Access and phenomenality are identified for accessed content only; accessible content stays preconscious. — Deep NREM sleep is rated probably unconscious; light NREM is added as the reportable state closest to the floor. — A test for systems that cannot report: in an inspectable system, trace a signal to the self model closed with the world model. — Principle 3 is stated as an identity (phenomenality is closure), with refutation conditions stated separately from the markers. — Corrected closure falsifier, a revised entry on recurrent processing theory, six further theory comparisons, and a revised position on panpsychism. No prediction or published result changed. Two falsification criteria were added and one was rewritten. Full changelog in the Zenodo record.

Contribute

For computer-science students Run a registered experiment The theory is tested in code by a programme called crucible: small, falsifiable experiments on rate networks, spiking networks, simulated bodies and one small quadruped robot. Each experiment’s hypothesis, falsifier and analysis are committed before the code that produces the data exists. Nothing in crucible is claimed to be conscious, and null results are reported on the same footing as positive ones. Experiments planned to open to outside contributors: — CRU-70: does a longer return path for the self-loop cost function, and not only wiring? Independent replication on fresh seeds. A laptop CPU is enough. — CRU-78: can a self-model block own the network’s dominant dynamical mode as the network grows? Replication of the control experiment; CPU, with a GPU for the full grid. — KIT-S0 / KIT-S1: health calibration and self-information scaling in large plastic spiking networks. Needs a large GPU; opens when the code is public. — R1: where a reactive, symbol-free robot controller sits on the branching-ratio scale while it performs a real task. Needs a legged or wheel-legged robot; opens once the event definition is fixed. The rules: register before you run, run exactly the registered grid with your assigned seeds, and return every row, including the failed ones. Unregistered runs cannot count. Registration is not open yet; the code is being prepared for public release. Full primer: research.matthiasgruber.com/experiments/

In preparation since MoC7

📖 No Outside The Limits of Mathematics and Logic From Any First-Person Perspective · book Every observer is part of what it describes. The book follows that one fact through mathematics, logic and physics, and asks which limits it imposes on any describer, human or machine.
♾ Limits Without an Outside Why the Limits of Embedded Description Travel as Refutations A describer that is part of what it describes cannot hold its own current act as content, and cannot certify its description of the whole as complete. The paper states five such limits and argues that they hold as refutations: denying them contradicts what every claimant already presupposes.
👉 Pointing Is Not Defining The Definition of Consciousness Is Not Settled Pointing at "something it is like" fixes the target only for uncontested cases. For unresponsive patients, infants, animals and machines it does not, and none of the twelve formulations examined settles those cases. A test programme for consciousness needs a definition that does.
🗺 Where the Theories Sit An Architectural Coordinate System for Comparing Theories of Consciousness, with the Four-Model Theory as Reference Frame Theories of consciousness are compared claim by claim, not as wholes. Each claim of nineteen theories is placed on a reference architecture as absorbed, compatible, neutral or contradicting, and every contradiction is paired with the experiment that would decide it.
⏱ Too Late to Report Why First-Person Methods Cannot Reach the Minimal Self The minimal self is pre-reflective, but reporting on it requires the system to take its own state as an object, which is the reflective step the minimal self lacks. Interviews, however skilled, therefore return a reflective reconstruction. The paper says what such reports can still deliver.
🔋 Silent Suffering A Plea to Consciousness Science and Robotics If artificial consciousness arrives, it is more likely to arrive in an embodied robot than in a language model, built by engineers who are not checking for it. Its suffering would be silent. The paper asks both fields for precautions that can start now: looking for it, and not training aversive states into a self-model where no task needs them.
