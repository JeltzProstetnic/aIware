# AIW-47 Salami-Slice — Venue Analysis

**Tracked-by: AIW-47.** Researched Session 216 (2026-06-10) from official author-guideline pages.

## Headline finding (changes the plan)
The original AIW-47 brief assumed a **non-APC** short-format venue. **No credible PubMed/Scopus/WoS-indexed venue is free.** Every viable target charges **~$1,900–2,400 APC**. The only free/diamond theory-native venue (NBDT) is NOT PubMed/Scopus/WoS indexed.
→ **Decision required before drafting: pay ~$2k for an indexed venue, or accept an unindexed free venue.** (The prior NoC-fee balk parked AIW-14 — this is a real gate for this project.)

## Top 3 (indexed)
1. **eNeuro — Opinion** *(RECOMMENDED)*. 4,000 words (exact fit). **DOUBLE-BLIND** — the only structural protection against affiliation-gatekeeping for an unaffiliated author (reviewers never see there's no institution). APC **$1,945** non-member ($1,305 SfN member). PubMed/Scopus/WoS. Portal: eneuro.msubmit.net.
2. **Neuroscience of Consciousness — Rapid Communications** *(equal #1 on impact)*. 3,000 words (needs tight trim). **Single-blind** (no affiliation shield). APC **€2,144**. IF 4.3, the field's home journal → max visibility among target readership. ScholarOne: mc.manuscriptcentral.com/nconsc.
3. **NeuroImage: Reports — Theory/Conceptual.** ~4–5k words; openly invites "theory or conceptual positions"; the EEG/MEG criticality angle fits the neuroimaging remit. ~$1,800–2,200 APC. **CAVEAT: not clearly PubMed-indexed** (Scopus/Embase/DOAJ only).

## Knockouts
- **PeerJ** — explicitly excludes hypothesis/opinion/commentary.
- **F1000Research** — requires institutional affiliation (direct independent knockout); indexing conditional; $1,595.
- **TICS Forum/Letters** — 1,200 words, largely commissioned, bans unpublished simulations.
- **Frontiers Hypothesis & Theory** — 12,000 words (our paper too short to look credible), ~$3,500 APC.
- **NBDT** — free/diamond, theory-native, CC BY, BUT DOAJ-only (fails indexing requirement). Fallback only if indexing can be relaxed.

## Recommendation
Lead: **eNeuro Opinion** — double-blind neutralizes the affiliation risk outright, 4k-word slot is a glove fit, mid-range fee, solid indexing. Equal-defensible: **NoC Rapid Comm** if maximizing consciousness-community visibility and comfortable with single-blind (highest IF).
