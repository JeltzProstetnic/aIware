*Section 2.7.* A paragraph after the mutualism argument names the readout fallacy: inferring the structure of a capacity from the structure of the data an instrument can read out of it. Gruber (2015, p. 45) made the point about the factor hierarchy of IQ data: the hierarchy shows how the performance data a typical IQ test collects are structured, not how intelligence is structured. The fallacy reaches every stratum of the CHC hierarchy, since each stratum was identified by factoring test scores.
