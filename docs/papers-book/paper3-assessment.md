## What paper 3 would argue (from v0.6 Ch 14, S336 rulings D1/hole 2/hole 4/M1)

- **Claim (conditional):** if a simulated organism has experience at all, a *static, realized* record of its whole
  trajectory has it too. What matters is the internal dependency structure of the realized states. Execution on a
  host does not matter.
- **Five operations kept apart:** live run / reschedule / reverse enumeration / inverted computation (Bennett:
  uncomputation needs the forward record) / static encoding. Plus three senses of "interrogate".
- **Triviality (Putnam, the dust theory) answered without Chalmers's counterfactual criterion.** A free reading needs a
  dictionary, and a dictionary is an object in the world, as long as the trajectory it recovers. In-world description
  length is bookkeeping for *where* a structure is stored (hole 2). The outside-the-universe count is not a
  perspective (S336).
- **What has an inside:** FMT's architecture (self-model and world-model closed on each other) in a *realized*
  trajectory. Rule + initial state = potential only (D1). Execution is not needed, realization is. This is where the
  view parts from Tegmark.
- **Description/instance is perspectival:** the same structure is content for a reader and frame for an inhabitant.
  FMT §3.4.5 "reading the code is not having the experience" holds of the reader.
- **Consequence for FMT:** "running" = realized internal dependency, not host activity (→ AIW-285 correction list).
