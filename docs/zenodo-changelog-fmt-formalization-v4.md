**v4 (2026-10-02)**

Supersedes v3 (2026-08-12). Companion to the Four-Model Theory v16.

*Lemma L2 (universality and criticality).* Item (v) now cites Zenil (2010) on the conjecture that universality implies positive compression capacity, notes that compression alone cannot separate Class 4 from Class 3, and reports Sugiura et al. (2025), whose Theorem 3 ties exact universality to discontinuity on a dense set of inputs. Noise caps input resolution in any physical system, so the finite-resolution optimum (driven-stable, undriven-chaotic; Schuecker et al., 2018; Roig et al., 2026) is the relevant one, and the edge-of-stability conjecture is retained in that form.

*Measurement.* The regional criticality estimate now specifies its surrogate. It must remove causal transmission while preserving each region's temporal structure; a surrogate that shuffles each unit's activity across the whole recording keeps its rate but breaks its alignment with population-wide bursts, and so underestimates the null in a near-critical substrate.

*Exposition.* Section 3.1 introduces transfer entropy by the question it answers before giving the formula. Every formula is now set as mathematics; in earlier versions integrals, products, subscripts and superscripts printed as raw markup. Section 9 is retitled *Scope and Limits*. Several run-in lists are set as lists.

*References.* New citations were verified against their sources; one link was corrected.
