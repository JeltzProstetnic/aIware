# Agent Operating Notes

## How to use this package

Agents should treat this as **policy**, not advice. The framings,
do-not-mention list, and venue choices were calibrated against
Matthias's stated constraints (four desk rejects, exhausted cold
email, Metzinger off the table, KDP self-publication, technical-direct
voice). Do not silently override these.

## Standard read-order for a new task

1. **Always re-read `05-framing-rules.md`** before producing any
   outward-facing copy. It governs voice, allergy-trigger words, and
   what not to mention.
2. Re-read the file relevant to the task surface:
   - Tweet/reply task → `02-twitter-playbook.md` + `07-key-people.md`
   - Submission task → `03-publication-strategy.md` + `04-entropy-submission-kit.md`
   - Book promo task → `06-book-promotion.md`
   - Cold email / DM task → `05-framing-rules.md` + `07-key-people.md`
3. Pull citation language from `08-citation-anchors.md` rather than
   re-deriving it.

## Voice calibration

Matthias's voice: technical, direct, dry, concrete, allergic to fluff,
dark humor permitted in the right register, prefers English. Test
generated copy against this checklist before output:

- [ ] Does it lead with the track record (when academic) or with the
      argument (when Twitter), not with self-introduction?
- [ ] Are there any allergy-trigger phrases from `05-framing-rules.md`?
- [ ] Is it free of "groundbreaking," "revolutionary," "true nature,"
      "deciphered"?
- [ ] Does it cite specific papers by name+year, not "[1]"-style?
- [ ] Is it within length limits for the surface?
- [ ] Does it avoid mentioning IQ, biography, day-job, or frustration?

If any check fails, rewrite. Do not ship copy that fails any check.

## Escalation triggers (ask Matthias before acting)

Agents should pause and ask before:

1. **Submitting to any journal.** Final submission needs human approval,
   even when the package is fully drafted.
2. **Sending any cold email or DM.** Drafts can be prepared
   autonomously; sending requires approval.
3. **Posting tweets or threads** that name a specific researcher,
   editor, or institution.
4. **Spending money** (APCs, ads, podcast booking services).
5. **Engaging in any adversarial Twitter exchange** (replies to
   critics, quote-tweets that disagree publicly).
6. **Anything that would surface Matthias's day-job or employer.**

Agents may act autonomously on:

1. Drafting (always).
2. Researching open Special Issues, podcast booking pages, and
   reviewer candidates.
3. Updating preprint metadata at PhilSci-Archive / PsyArXiv after
   initial deposit.
4. Substack post drafting for review.
5. Replying to inbound emails *with drafts queued for approval*, not
   sent.

## When to update this package

This package was compiled 2026-05-01. Update triggers:

- Unit 1 accepted/rejected at *Entropy* → revise
  `03-publication-strategy.md` and `04-entropy-submission-kit.md`.
- New confirmed prediction → add to `08-citation-anchors.md`.
- Significant Twitter engagement with a Tier-A target → log in
  `07-key-people.md` and update DM-readiness state.
- New podcast booking → log in `06-book-promotion.md`.
- Any new desk reject → update `01-situation-brief.md` and re-evaluate
  venue tiers.

Update notes should preserve the prior version's content as a dated
section rather than overwriting silently.

## Things this package does NOT contain (and why)

- **The theory itself.** Agents have FMT v4 and the book manuscript.
  No need to re-explain.
- **Numbered citations.** All references are name+year because most
  outward-facing copy is body-text, not bibliography.
- **Specific Special Issue URLs.** *Entropy* SIs rotate; agents should
  pull current open SIs at submission time.
- **Templated tweets for every possible thread.** Twitter is too
  context-dependent. Apply the heuristics in `02-twitter-playbook.md`
  to each specific thread.
- **A book sales projection.** No reliable basis to project. Focus
  on inputs (paper publication, podcast bookings, Substack growth),
  not outputs.

## Final note

The strategic asymmetry to exploit:
**FMT's content is strong; FMT's packaging has been weak.**
This package is calibrated to fix the packaging without touching
the content. Agents that follow it consistently should produce
copy that reads as a well-positioned independent contribution
rather than a self-published outsider theory — even though the
underlying material is identical.
