## Operating principles (read first)

1. **Author voice is technical, direct, dry, no fluff, dark humor permitted.**
   Never write breathless "groundbreaking" copy. Matthias finds it embarrassing.
2. **The track record is the lede, not the dissolution of the Hard Problem.**
   Five 2015-derived claims confirmed by 2024–2026 empirical work is the
   strongest rhetorical asset. Lead with it. The Hard Problem framing is
   for *after* the foothold paper is published.
3. **Independent researcher + 64-page solo theory + "dissolves Hard Problem"
   = automatic desk reject.** Never submit the full integrative paper
   anywhere as the first move. Always lead with Unit 1 (criticality).
4. **English over German for all outward communication** unless the venue
   is explicitly German-language.
5. **Don't drop two PDF links in a single tweet** — reads as self-promo.
   Lead with the argument, link second, and prefer threads to single
   tweets when citation is needed.
