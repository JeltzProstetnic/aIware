## Theory-tradition citations (use when situating FMT)

When agents need to place FMT inside a recognizable lineage rather
than presenting it as standalone:

- **Self-modeling tradition:** Metzinger (2003, 2009), Damasio (1999,
  2010), Hofstadter (2007), Graziano (2013), Seth (2021).
- **Multiple drafts:** Dennett (1991).
- **Predictive processing:** Friston (2010), Seth (2021).

FMT extends the self-modeling tradition by adding (a) a minimal
architecture spec (four model kinds along two axes), (b) a physical
prerequisite (criticality), and (c) a two-level ontology (real
substrate / virtual computation).

## Theories FMT explicitly distinguishes itself from

When agents need to head off mistaken-identity replies:

- **Not illusionism** (Dennett 1991, Frankish 2016): qualia are real
  at the computational level, not illusions.
- **Not deflationary AST** (Graziano 2024): FMT holds qualia are
  constitutive, not merely the brain's schema of attention.
- **Not IIT** (Tononi 2004): FMT does not identify consciousness with
  integrated information; criticality is a different condition.
- **Not GNW** (Baars 1988, Dehaene & Changeux 2011): FMT is about
  what kind of computation has experience, not which information is
  globally broadcast.
