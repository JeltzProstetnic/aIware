## Book endorsement / blurb path (Matthias has exhausted cold email)

The remaining live channels are:

1. **Podcast hosts who read the book before interviewing** — natural
   blurb opportunity post-interview. Mind Chat and TOE have done this
   for prior independent guests.
2. **Substack reviewers** (Hoel, Brander, others) — review functions
   as de facto blurb. Send a review copy with a short note, not a
   blurb request.
3. **Twitter mutuals built through engagement** — once an author has
   ~5 substantive exchanges with a researcher, a book-mention request
   becomes legitimate. This is the slow path but it's the one that's
   open.

## DM hygiene rules

1. Never DM cold. Public engagement first.
2. One link maximum per DM.
3. ≤120 words.
4. Specific ask in last sentence.
5. If no reply in 10 days, do not follow up. Move on.
6. Never DM more than one Tier-A target per week.
